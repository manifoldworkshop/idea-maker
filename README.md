# Idea Maker

This repository collects ideas of all kinds (products, experiments, creative projects, joyful pursuits) and the supporting skills used to create and maintain them.

## Contents

- `ideas/`: Idea entries. Each idea lives in its own folder with an `IDEA.md` and optional supporting materials.
- `skills/`: Skill definitions, templates, and assets for generating or maintaining idea documentation.

## Getting started

1. Browse existing ideas in `ideas/`.
2. Add a new idea by following the instructions in `ideas/README.md`.
