# Ideas

This folder stores idea entries under `ideas/<idea-name>/`. Ideas can be products, experiments, personal projects, or anything worth exploring further.

## Add an idea (manual)

1. Create a folder: `ideas/<idea-name>/`
2. Add `IDEA.md` using the template in `skills/idea-maker/assets/templates/idea.md`
3. Add optional support materials:
- `references/` for research, PRD, risks, metrics
- `assets/` for images or sketches
- `files/` for miscellaneous supporting files
